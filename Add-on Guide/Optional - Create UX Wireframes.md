# WoW Add-on UX Wireframes (Draw Only)

**Read `References/Pass Preamble.md` first; it governs everything below.** Pass Name: `the Create UX Wireframes Pass`. Write scope: **nothing. The wireframe is an Artifact, never a file in the add-on folder.**

Draw a clickable wireframe of every window this add-on shows, **exactly as it is now**, so the maintainer can share the link with players for usability testing. Nothing is reviewed or proposed here; that is `02 - UX Review.md`. No questions either: draw what the code does.

Run it whenever testers need a link. Nothing keeps the wireframe current between runs; a rerun rebuilds it from the code, at the same link.

## Workflow: three phases (0–2), all required

0. **Permissions.** Follow the preamble. The Artifact publish asks for approval, and that prompt is expected: approve it with a plain **Yes**.

1. **Map every surface** per `02 - UX Review.md` → phase 1, and find the last wireframe titled `{Add-on Name} UX Wireframes` per its phase 3, without the questions. A rebuild replaces any Proposed view a UX Review left there; if that view still has changes with no choice made, say so in one line before publishing.

2. **Draw and publish** per `02 - UX Review.md` → Wireframe Build: **Current** only, plus the per-state views and the **Try this** lists. No change cards and no approvals. Give the maintainer the link, and tell them it stays private until they share it from the page's Share menu.

This pass does not audit the docs. If you run into a genuine doc problem, mention it in one line and move on.
