Options Panels

Every Active add-on's options panels, drawn from its code on GitHub main, in the Settings window as the game draws it. Flip Today and Proposed to see the same page before and after Options-Kit. The switches work: tick one on the root page and its panel follows.

How to reviewEach add-on's window shows its whole tree. The root page and the panels that change most are drawn in full; the rest name what changes and point at the spec. Turn on Show components to see which kit piece draws each row, and which rows today break a rule (red). Profiles, Feedback & Support and Diagnostic Tools are inherited or templated: they sit in every tree and nothing here touches them. Decisions 5 to 13 change what players see; all sixteen are decided, and the Style Guide says each one now.
