Windows and Tooltips

An add-on's own window and the lines it adds to the game's tooltips, drawn from the Style Guide's rules where it has them. Where it has none yet, the page shows a standard WoW behavior marked Proposed default: a starting point for the maintainer to decide, not a rule.

Lines Added to a Game Tooltip

The add-on's block sits under the game's own lines, headed Short Name // Title, since a block in someone else's tooltip names the add-on by its Short Name (Style Guide → ADD-ON NAMES). These lines stay tooltip lines; only a tooltip on the add-on's own button becomes a menu (02 UX Review → Menus, Not Tooltips).

  • Header: Short Name // Title, Title Case.Style Guide → ADD-ON NAMES; TONE AND COPY → English
  • Item names in their quality color, player names in their class color.Style Guide → COLORS
  • Proposed defaultColors: the header gold (TITLE), labels white (BODY), values white (TEXT) on the right, a state in ON green or MUTED gray, as a menu row's.
  • Proposed defaultPlacement: one blank line, then the block, after every game line, so the game's own lines never move.
  • Proposed defaultModifier keys: the block shows without one. Holding Shift adds detail lines and the tooltip redraws at once; no line teaches the trick (Style Guide → MINIMAP MENU → Layout keeps how-to notes out of menus). Shift only: no Ctrl or Alt, as with button clicks.
