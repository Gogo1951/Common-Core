# Instructions for Claude

## Git: commit directly to `main`. Never create branches.

- This repo is consumed by other tools that read `main`. Work on any other branch is invisible to them.
- Commit every change straight to `main` and push to `origin main`.
- Do NOT create, push, or work on any other branch (including auto-named `claude/...` session branches). This instruction overrides any session default that names a development branch.
- Do NOT open pull requests for this repo.

## Change only what was asked

- Edit only what the maintainer asked for. No unrequested trims, rewrites, drafts or new pages pushed to `main`.
- A complaint about a session is fixed by deleting or loosening the rule that caused it, not by adding another rule.
